Syntax reference

      
    

    

      
JSpice reads two formats and detects which one you wrote. Node 0 is always ground.

      
SPICE netlist

      
The first line is a title comment. Lines starting with * are comments.


* title
R1 in out 1k          * resistor
C1 out 0 100n         * capacitor
L1 out 0 10m          * inductor
V1 in 0 5              * DC voltage
V2 in 0 SIN(0 1 1k)    * offset amplitude freq
V3 in 0 PULSE(0 5 0 1u 1u 5m 10m)
*   v1 v2 delay rise fall width period
YMEMRISTOR MR1 a b MODEL
.model MODEL memristor ( Rinit=1k Ron=500
+ Roff=1.5k Von=0.27 Voff=0.27 Tau=0.1m )
.tran 10u 20m        * step stop
.end

      
Without .tran, JSpice computes the DC operating point. Value suffixes: f p n u m k meg g t.

      
YAML netlist

      
Supports every component, including diodes, MOSFETs and controlled sources, and DC sweeps.


components:
- type: resistor     # resistance
  id: R1
  nodes: a,b
  resistance: 1000
sim:
  type: sweep          # or dcop, trans
  sweep_id: V1
  observe_id: V(b)
  start_value: 0
  end_value: 5
  step_size: 0.05

nmos, pmosthreshold (nodes: gate,drain,source)
