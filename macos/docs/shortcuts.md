# Keyboard shortcuts

The app lists these in **Help ▸ Keyboard Shortcuts** (⌘/, or `?` on the canvas), with every part's key. Part keys are also shown next to each part in the library.

## Drawing

| Key | Action |
| --- | --- |
| letter keys | choose a part (a letter for the common ones, ⇧ and a letter for the rest) |
| `⌘K` or `/` | add a part, example or command by name: the palette (Circuit ▸ Add Part…) |
| `Esc` | step back one level at a time: abandon a drag, close the value being typed, cancel a MIDI Learn, put the tool away, then clear the selection |
| click / drag | place the chosen part / set its length and direction |
| drag a part | move it; wires attached to it stretch |
| drag an end | resize or turn the selected part |
| `W` | wire |
| `G` | ground |
| `H` | net label: labels with the same name are connected; `GND` is ground |

## Editing

| Key | Action |
| --- | --- |
| `⌘Z` / `⇧⌘Z` | undo, redo |
| `Delete` | delete the selection |
| `⌘D` | duplicate the selection (Edit ▸ Duplicate) |
| arrow keys | nudge the selection (⇧: five units) |
| `⌘R` | rotate the selection (Circuit ▸ Rotate) |
| `F` or `⇧⌘R` | flip the selected transistors, op-amps, OTAs, chips and potentiometers (Circuit ▸ Flip) |
| `Tab` / `⇧Tab` | select the next or previous part |
| `⌘A` `⌘C` `⌘X` `⌘V` | select all, copy, cut, paste |
| `⌥⌘T` | tidy up: redraw the circuit as a neat schematic (Circuit ▸ Tidy Up) |
| `⇧⌘B` | save the circuit as a block (Circuit ▸ Save as Block…) |

## View and simulation

| Key | Action |
| --- | --- |
| `Space` or `⌘↩` | run or pause (Simulation ▸ Run or Pause) |
| `⇧⌘↩` | reset to time zero (Simulation ▸ Reset) |
| `⌘=` `⌘-` `⌘0` | zoom in, out, to fit (View menu) |
| scroll, `⌘` + scroll, pinch | pan, zoom, zoom |
| `⌥` + drag on empty canvas | pan |
| scroll over a potentiometer | turn it |
| `.` | flip the selected switch, footswitch or jack; hold the selected push button down while the key is held |
| `[` / `]` | turn the selected potentiometer down, up 5 % (⇧: 1 %) |
| right-click a part | add a scope, I–V curve, frequency response or spectrum; MIDI Learn; rotate, flip, delete (the same for the selected part: Circuit ▸ Measure, MIDI Learn, Forget, Open Block, Update from Library) |
| `⇧⌘E` | export the schematic as an image (File ▸ Export ▸ Image…) |
| `⌘U` | upload the selected microcontroller's sketch (Microcontroller ▸ Upload Sketch) |
| `⌘/` or `?` | show the keyboard shortcuts (Help ▸ Keyboard Shortcuts) |
| `⌘,` | settings: AI control, the API key, chip support |

## Playing

With sound on and a keyboard source in the circuit ([guide.md](guide.md#sound)):

| Key | Action |
| --- | --- |
| `A W S E D F T G Y H U J K O L P ;` | notes from C, like a piano keyboard (as in GarageBand) |
| `Z` / `X` | octave down, up |
